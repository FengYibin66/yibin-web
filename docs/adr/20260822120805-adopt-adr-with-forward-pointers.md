# 20260822120805. 引入 ADR 制度：不可变 + 前向指针 + 生成式索引

- 状态：已接受
- 索引：决策记录用时间戳 ID 的不可变 ADR；被后续修订时只改旧 ADR 的 `状态：`/`索引：` 两个字段追加前向指针；索引表由脚本生成不手改
- 日期：2026-08-22

## 背景

本仓库此前没有任何决策记录。架构决策的理由只存在三处：作者记忆、commit message、`docs/ARCHITECTURE.md` 里一段名为「Key Design Decisions」的六条 bullet：

```
1. Monorepo: Single repo for coordinated development & deployment
2. Unified Docker Compose: All services orchestrated together in production
3. Shared Database: Portal & Auto-Wechat share MySQL (different schemas)
...
```

这段有三个致命缺陷，正好说明为什么需要 ADR：

1. **无备选、无理由**——只说"选了什么"，没说"为什么不选别的"。后来者（含 AI）无法判断这个决策的**边界**：什么情况下它仍然成立、什么情况下应该推翻。
2. **无影响与代价**——没有一条写了负债。于是负债不被跟踪，最终以事故形式出现（如全量构建、单点故障从未被承认过）。
3. **已经在说谎**——第 3 条「Portal & Auto-Wechat share MySQL」与实现不符（见 ADR 20260822120802）。因为它没有日期、没有状态、没有对应实现的锚点，错了也没人能发现。

在 AI 协作下，第 1 条的代价被显著放大：agent 每次都要从代码反推意图，而代码只能表达"是什么"，永远无法表达"为什么不是别的"。它于是会做出局部合理、全局违背原设计的改动。

## 选项

- **A. 继续用 `ARCHITECTURE.md` 的 bullet 列表**：零成本；但上述三个缺陷全部保留。
- **B. 可变的决策文档**（决策变了就直接改原文）：始终反映现状；但**丢失决策演化史**——无法回答"当初为什么这么选、后来为什么改"，而这恰恰是新人和 AI 最需要的信息。且改动无痕，无法 review。
- **C. 不可变 ADR + 前向指针**：每份 ADR 是一个时间点的快照，永不重写；被修订时在旧文件追加指向新 ADR 的注记。
- **D. 不可变 ADR 但不加前向指针**（教科书式 ADR）：保留历史；但读到旧 ADR 的人无法知道它是否仍然有效，必须通读全部 ADR 才敢用任何一条——这是 ADR 制度在实践中失效的最常见原因。

## 决策

选 **C**。判定原则：**决策记录不可变，但必须自带「我是否仍然有效」的元信息**。

三条具体机制：

1. **ID 用创建时刻的 `date +%Y%m%d%H%M%S`**，而非递增序号。并行开分支时序号必撞，时间戳不会。
2. **修订不改正文，只改两个字段**：旧 ADR 的 `状态：` 与 `索引：`。后者追加形如「注记：X 部分已被 `<新ID>` 修订为 Y；其余结论不受影响」。这一步是整套制度可扩展的关键——**没有它，一份被局部修订的 ADR 会被整体误判**：要么整体当过期而丢掉仍有效的结论，要么整体当有效而用了过期的部分。
3. **索引表是生成物**（`scripts/docs/gen_docs_index.py`），人只维护每份 ADR 头部的 `索引：` 字段。手维护的索引表在文档超过十几份后必然与实际脱节，而脱节的索引比没有索引更糟——它会让人停止怀疑。

**什么该写 ADR、什么不该**：ADR 记录**有备选方案的选择**。若只有一个可行方案，那不是决策而是事实，应写进 `docs/architecture/` 或对应目录的 `AGENTS.md`。判据：写不出两个真实备选，就不该是 ADR。

## 影响

- 正面：决策的理由、边界、代价可被人和 AI 复用；负债被显式跟踪而非遗忘；追认过程本身就发现了一处文档说谎（ADR 20260822120802）。
- 负面：每个架构决策多一份文档的写作成本。缓解：只对有备选的决策写，个人项目预期年增十余份而非上百份。
- 影响面：新增 `docs/adr/`（含 `TEMPLATE.md`、`AGENTS.md`）、`scripts/docs/gen_docs_index.py`；`docs/ARCHITECTURE.md` 的「Key Design Decisions」段落改为指向 `docs/adr/`，不再承载决策理由。
